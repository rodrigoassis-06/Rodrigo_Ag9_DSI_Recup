# Desafio Visual: Meu Painel de Dados com Listas - Agenda 09 DSI (Recuperacao)

Atividade de recuperacao da Agenda 09 de Desenvolvimento de Sistemas I.

## Descricao

Explicacao visual e estruturada da logica de programacao do programa de gerenciamento de tarefas com listas em Python:
- Entrada de dados (nome, cidade, quantidade e tarefas);
- Manipulacao dinamica de listas com `append()`;
- Iteracao com laco `for`;
- Tomada de decisao com `len()` e estruturas condicionais (`if/elif/else`).
